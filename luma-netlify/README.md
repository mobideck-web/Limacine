# Luma — Netlify deployment

This directory contains the Luma — Your cinema application adapted from Sites version 8 for a Netlify Next.js deployment.

- Netlify base directory: `luma-netlify`
- Build command: `npm run build`
- Publish directory: `.next`
- Node.js: 22

The root application and existing projects in this repository are not replaced by this snapshot. Future changes made in the Sites project are not automatically synced to this directory.

Movie/series searches use Wikipedia and Wikidata, episode details use TVmaze, and players are provided by third parties. Provider availability and subtitle tracks vary.
